Now that we can write brms’s syntax and read its output, we can brave more complicated models. Let us consider some data from park visitors, gathered by UCLA1. In their words:

The state wildlife biologists want to model how many fish are being caught by fishermen at a state park. Visitors are asked whether or not they have a camper, how many people were in the group, were there children in the group and how many fish were caught. Some visitors do not fish, but there is no data on whether a person fished or not. Some visitors who did fish did not catch any fish […]2

These data describe 250 groups of park visitors. For each group, we know how many fish they caught (count), how many total people were in the group (persons), how many of these were children (child), and whether the group brought a camper vehicle (camper).

fisher_df <- read.csv("https://paul-buerkner.github.io/data/fish.csv")
fisher_df <- fisher_df[, c("persons", "child", "camper", "count")]
names(fisher_df)[names(fisher_df) == "count"] <- "num_fish"
fisher_df <- fisher_df |>
  mutate(camper = as.factor(if_else(camper == 0, true = "no", false = "yes")))
summary(fisher_df)

Note that many visitor groups caught zero fish (see Figure 5.1). These include zeroes from visitors that did not fish at all and zeroes from visitors that did fish but caught nothing.

Show histogram of fish caught 
fish_hist <- ggplot(data = fisher_df, mapping = aes(x = num_fish)) +
  geom_histogram(binwidth = 2, color = "black", fill = "navyblue") +
  labs(
    title = "Many groups did not catch any fish",
    x = "Fish caught",
    y = "Groups of visitors"
  ) +
  theme_bw()
fish_hist

It is reasonable to think that larger groups were more likely to catch more fish. Also, groups with campers likely stayed longer at the park, which would give them more time to fish. And children tend to dislike sitting in silence for long periods, so groups with more children may have fished less. These ideas suggest using a model that can associate the average number of caught fish to persons, child, and camper. We should also use a model that accounts for the fact that the number of fish caught is a non-negative integer. A Poisson regression is a relatively simple model that can fulfil both of these requirements3.

An alternative to priors based on previous measurements is to use priors that discard implausible values but still allow wide ranges for all coefficients4. One common approach for this is to standardize all numerical dependent variables and assign them all a Normal distribution with mean zero and standard deviation 15.

for (var_name in c("persons", "child")) {
  var_name_std <- paste0(var_name, "_std")
  fisher_df[[var_name_std]] <- scale(
    fisher_df[[var_name]],
    center = TRUE,
    scale = TRUE
  )
}

The code to prepare these rescaled priors is below.

prior_fisher1 <- prior(prior = std_normal(), class = "b") +
  prior(normal(0, 2.5), class = "Intercept")

Now we can fit our regression. The only novelty in the code below is the argument family, which controls the type of model we want to fit—in this case, a poisson().

fit_fisher1 <- brm(
  formula = num_fish ~ persons_std + child_std + camper,
  data = fisher_df,
  family = poisson(),
  prior = prior_fisher1,
  chains = 4,
  cores = 4,
  iter = 1000,
  warmup = 500
)

Once again, our ESS and R-hats are all acceptable:

Before we examine the coefficients, we can check if our model can replicate the overall pattern of fish caught. The function pp_check() can paint many types of plots to illustrate how well our models fit the data. It asks us to define a model to evaluate and the type of evaluation we want. type = "bars" compares a barplot of the original data (shown as \(y\) in clear blue) to the predictive intervals obtained from the random draws in our model (shown as \(y_{rep}\) in dark blue).

fisher1_pred <- pp_check(
  object = fit_fisher1,
  type = "bars",
  ndraws = 600,
  prob = 0.9 # for 90% credibility intervals
) +
  coord_cartesian(xlim = c(0, 30)) +
  labs(
    title = "Poisson replicates data poorly",
    x = "Number of fish caught",
    caption = "90% predictive intervals"
  ) +
  theme_minimal()
fisher1_pred

Figure 5.2 shows that our model is predicting too many visitors with one, two, and three fish and too few visitors with zero fish. This suggests that, unfortunately, our current Poisson regression cannot account for these many zeroes, and in trying to do so it is distorting our inferences.

5.1 Handling excess zeroes

Fortunately, brms can expand our model so it directly estimates the proportion of groups that did not fish at all. This expanded model is called “zero-inflated Poisson regression” because it inflates (i.e., adds more) zeroes to the basic Poisson regression. For now, we presume that all groups had the same chance of going fishing. We do not change the default prior for the zero-inflation parameter, so the code to fit this zero-inflated regression is almost the same as before. The only change is that we now set the family to zero_inflated_poisson().

fit_fisher_zinf <- brm(
  formula = num_fish ~ persons_std + child_std + camper,
  data = fisher_df,
  family = zero_inflated_poisson(),
  prior = prior_fisher1, # Reuse prior from before
  chains = 4,
  cores = 4,
  iter = 1000,
  warmup = 500
)

Let’s see if our clever use of zero inflation paid off. First, it seems that our zero-inflated Poisson replicates well the overall pattern of fish caught (see Figure 5.3).

fisher_zinf_pred <- pp_check(
  object = fit_fisher_zinf,
  type = "bars",
  ndraws = 600,
  prob = 0.9
) +
  coord_cartesian(xlim = c(0, 30)) +
  labs(
    title = "Zero-inflation improves the model fit",
    x = "Number of fish caught",
    caption = "90% predictive intervals"
  ) +
  theme_minimal()
fisher_zinf_pred

We can also inspect the proportion of visitors with zero fish by calling pp_check() again. The code is similar to the one above, but we now use type = "stat" and add a custom function to compute the proportion of zeroes in a vector:

# Define a function that computes the proportion of zeroes
prop_zeros <- function(y) mean(y == 0)
fisher_zinf_zeroes <- pp_check(
  object = fit_fisher_zinf,
  type = "stat",
  stat = "prop_zeros",
  binwidth = 0.01
) +
  labs(
    title = "Zero-inflated Poisson captures zeroes well",
    x = "Proportion of visitor groups that caught zero fish"
  ) +
    coord_cartesian(xlim = c(0.3, 0.8)) +
    theme_minimal() +
    theme(legend.position = "bottom")
fisher_zinf_zeroes

The figure above compares the observed proportion of zeroes (shown in navy blue) to the proportions predicted based on our model’s random draws (shown in light blue). As this histogram shows, our zero-inflated poisson accurately predicts the proportion of zeroes.

For mathy reasons, the regression coefficients are in the natural logarithm scale, which complicates their interpretation. So, instead of deciphering the table, we can call conditional_effects() to plot the modeled associations between each variable and the average number of fish. The plots below show the medians and 80% credibility intervals of the posterior distributions of average fish at each value of the corresponding independent variable. When a variable is not shown in a plot, we are fixing its value at either its average (for continuous variables) or its reference category (for categorical variables).

We start by visualizing the association between average fish caught and the number of people in a group:

conditional_effects(
  x = fit_fisher_zinf,
  method = "posterior_epred",
  effect = "persons_std",
  prob = 0.8 # For 80% credibility intervals
)

The main lesson from Figure 5.5 is that groups of visitors with more people caught more fish on average, but the difference was not big. With some effort, we can use ggplot to embelish this plot. We do the same for the associations of children and camper and show them together in Figure 5.6.

Grouped plots for conditional associations 
# Number of people
persons_mean <- mean(fisher_df$persons)
persons_sd <- sd(fisher_df$persons)
person_assoc <- plot(
  conditional_effects(
    x = fit_fisher_zinf,
    method = "posterior_epred",
    effect = "persons_std",
    prob = 0.8
  ),
  plot = FALSE
)[[1]] +
  labs(
    title = "Larger groups caught\nmore fish",
    x = "People",
    y = "Average number of fish caught"
  ) +
  scale_x_continuous(
    name = "Number of persons",
    breaks = (1:4 - persons_mean) / persons_sd, # adjust to your data range
    labels = 1:4
  ) +
  theme_bw()
# Children
child_mean <- mean(fisher_df$child)
child_sd <- sd(fisher_df$child)
child_assoc <- plot(
  conditional_effects(
    x = fit_fisher_zinf,
    method = "posterior_epred",
    effect = "child_std",
    prob = 0.8

  plot = FALSE
)[[1]] +
  labs(
    title = "Children caught fewer\nfish",
    x = "Children",
    y = "Average number of fish caught"
  ) +
  scale_x_continuous(
    name = "Number of persons",
    breaks = (1:4 - child_mean) / child_sd, # adjust to your data range

  ) +
  theme_bw()

camper_assoc <- plot(

Now let’s review the part of summary that refers to the zero-inflation parameter:

Further Distributional Parameters:
   Estimate Est.Error l-80% CI u-80% CI Rhat Bulk_ESS Tail_ESS
zi     0.41      0.04     0.35     0.47 1.00     1582     1243

In general, the parameter zi (short for “zero inflation”) represents the probability of an observation being an excess zero. In our model, we can interpret zi as the probability of not going fishing. With our current credibility criterion, this probability is estimated to be between 35% and 47%.
